These projects complement my later work in Java, SQL, data analytics, and automation. They demonstrate foundational experience with hardware-oriented programming and digital systems.

## Migration and validation

The source came from `ProyectoDD.zip` and `Practica2.zip`. Build outputs, workspace metadata, browser caches, and macOS sidecar files were excluded. The original Drive archives remain unchanged.

The [file manifest](docs/source-manifest.json) records the original archive path and exact Git blob hash of each imported file. File integrity was verified after publication. Quartus synthesis, hardware execution, and CCS compilation have not been tested in this environment.
